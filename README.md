# Customizing the Blazor Kanban Edit Dialog Using Templates

A small Blazor sample demonstrating how to customize the edit dialog for the Syncfusion Blazor Kanban component with templates. The project includes dialog templates and example code for creating, reading, updating, and deleting cards using the Kanban dialog UI.

## Overview

This sample shows how to replace the default edit dialog with a custom template to control the layout and inputs users use to edit card data. It also demonstrates integrating dialog-based editing with the Kanban CRUD workflow.

Documentation: https://blazor.syncfusion.com/documentation/kanban/dialog#dialog-template

Online sample: https://blazor.syncfusion.com/demos/kanban/dialog-editing?theme=bootstrap5

## Features

- Custom dialog templates for card editing
- Dialog-driven create/update/delete examples
- Example bindings between dialog fields and card data

## Prerequisites

- Visual Studio 2022 (or later)
- The .NET SDK required by the solution

## Run the project

1. Clone the repository to a local folder.
2. Open the solution in Visual Studio 2022.
3. Restore NuGet packages by rebuilding the solution or run `dotnet restore`.
4. Build and run the project from Visual Studio.

Optional CLI commands:

```powershell
dotnet restore
dotnet build
```

## Troubleshooting & support

If you encounter issues, confirm that packages are restored, the project builds, and the license key is registered correctly. For more details about Syncfusion components consult the Syncfusion Blazor documentation.
