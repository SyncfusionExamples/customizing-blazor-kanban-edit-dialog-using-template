# Customizing the Blazor Kanban Edit Dialog Using Templates

A small Blazor sample demonstrating how to customize the edit dialog for the [Blazor Kanban](https://www.syncfusion.com/gantt-sdk/blazor-kanban-board) component with templates. The project includes dialog templates and example code for creating, reading, updating, and deleting cards using the Kanban dialog UI.

## Overview

This sample shows how to replace the default edit dialog with a custom template to control the layout and inputs users use to edit card data. It also demonstrates integrating dialog-based editing with the Kanban CRUD workflow.

## Features

- Custom dialog templates for card editing
- Dialog-driven create/update/delete examples
- Example bindings between dialog fields and card data

## Getting Started

### Prerequisites

* [.NET SDK 10.0](https://dotnet.microsoft.com/en-us/download/dotnet/10.0) or later
* Visual Studio 2026 or [Visual Studio Code](https://code.visualstudio.com/)

### Clone the repository

```bash
git clone https://github.com/SyncfusionExamples/customizing-blazor-kanban-edit-dialog-using-template.git
cd customizing-blazor-kanban-edit-dialog-using-template
```

### Run with Visual Studio

1. Open the solution file using Visual Studio 2022 or later.
2. Restore the NuGet packages by rebuilding the solution.
3. Build the project to ensure there are no compilation errors.
4. Run the project.

### Run with .NET CLI

```bash
# Restore dependencies
dotnet restore

# Run the project
dotnet run
```
